PART 1 : Java Fundamentals

1. What is Java ?
- Java is a high-level, Object-Oriented, class-based, platform independent programming language developed by 
Sun Microsystems. It is widely used for developing, enterprising application, web-application, Android application and backend systems.

For example :
  - Banking applications
  - E-commerce applications
  - Enterprise Software

---------------------------------------------------------------------------------------------------------

- Features of Java :

~ Platform Independent : Java code can run on different operating system using JVM.
~ Object-Oriented : Java supported classes & objects.
~ Simple : Java hava realtively simple syntax compared with languages like C++.
~ Secure : Java provides bytecode verification, class loading & security mechanism.
~ Robust : Strong memory management and Exception Handling.
~ Multithreaded : Supports executing multiple threads concurrently.
~ Portable : Java bytecode can run on different platforms.
~ High Performance : JIT compliers optimizes frequently executed code.
~ Distributed : Support network-based and distributed application.
~ Dynamic : Classes can be loaded at runtime.

- How Java Code Executes

    ~ Java source code is written in a .java file.
    ~ Java compiler converts source code into bytecodes.
    ~ Class loader loads the required class.
    ~ ByteCode Verifier check bytecode validity.
    ~ JVM executes the bytecode through its execution engine.
    ~ JIT compiler optimizes frequently executed code into native machine code.

- Variables in Java 
    - A variable is a named memory location used to stored data.
    - Java has three types of variable 
        1. Local Variables
        2. Instance Variables
        3. Static Variables

---------------------------------------------------------------------------------------------------------

~ Local Variable :
    - Variable declared inside a method, constructor or block.
    - IMP :
        ~ Must be initialized before use.
        ~ Scope is limited to its block.
        ~ Does not get a default value.

---------------------------------------------------------------------------------------------------------

~ Instance Variable :
    - Variable declared inside a class but outside methods, constructor or blocks, withour the static keyword.
    - Each object gets is own instance variable

---------------------------------------------------------------------------------------------------------

~ Static Variable :
    - Variable declared using the static keyword.
    - A static variable belongs to the class and is shared among its instances.

- Data Type in Java :
    - Java is a statically typed language. Every variable must have a declared type.
    - Java has two categories of data type 
        1. Primitive Data Type
            - In primitive has 8 Data type :
                ~ byte : 8bits : byte a = 10;
                ~ short : 16bits : short a = 100;
                ~ int : 32bits : int a = 500;
                ~ long : 64bits : long a = 10000L;
                ~ float : 32bits : float a = 12.4f;
                ~ double : 64bits : double a = 12.45;
                ~ char : 16bits : char a = 'A';
                ~ boolean : JVM-dependent representation : boolean a = true;

        2. Non-Primitive Data Type
            - In non-primitive has 6 Data type :
                ~ String
                ~ Array
                ~ Classes
                ~ Interfaces
                ~ Enums
                ~ Records

---------------------------------------------------------------------------------------------------------

- Type Casting in Java :
    - Type casting means converting one data type into another.
    - In java, There are two types :    
        1. Widening Casting
            - Converting a smaller compatible numeric type into a larger type.
            - Eg :
                int number = 100;
                double result = number;
                System.out.println(result);

        2. Narrowing Casting
            - Converting a larger numeric type into a smaller type.
            - Eg :
                double number = 100.75;
                int result = (int) number;
                System.out.println(result);

- Operators :
    ~ Operators are symbols used to perform operations on variables and values.
    ~ Types of Operators :
        1. Arithmetic ( +, -, *, /, % )
        2. Relational ( ==, !=, >, <, >=, <= )
        3. Logical ( &&, ||, ! )
        4. Assignment ( =, +=, -=, *=, /= )
        5. Unary ( ++, -- )
        6. Bitwise ( &, |, ^, ~ )
        7. Shift ( <<, >>, >>> )
        8. Ternary ( condition ? value1 : value2 )
        9. Type Comparison ( instanceof )

- Difference Between == and .equals() ?
    ~ (==) compares primitive values. For objects, it compares references (whether both references point to the same object).
    ~ (.equals()) compare logical equality when the class implements or overrides it appropriately.

    - Control statement determine the flow of program execution.
    - Control statement in Java are used to control the flow of execution of a program based on condition, 
    decisions, and repetitions.

- Java 17 is a Long Term Support (LTS) release introduced in September 2021.
- It includes several important language and JVM improvements.

1. Records :
    - Records were introduced in Java 16 as a finialized feature.
    - A record is a special type of class designed to hold data with less boilerplate code.
    - Key pts :
        ~ Java automatically provides :
            - Constructor
            - Access Modifier
            - equals()
            - hashCode()
            - toString()

---------------------------------------------------------------------------------------------------------
- IMP : IQ 
- Are Records Immutable?
    - Records are shallowly immutable. Their component fields are final, so their reference cannot reassigned after construction. However, if a component refers to a mutable object, that object's contents can still change.

- Where are records useful?
    1. Data Transfer Objects (DTOs)
    2. API response objects
    3. Data carrier objects
    4. Configuration data
